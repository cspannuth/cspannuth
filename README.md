### [AI SQL Engine](https://github.com/cspannuth/AI-SQL-Engine)

A deterministic Java DBMS combined with isolated AI skill agents for querying and analyzing structured business data.

`Java` `Python` `SQL` `AI Agents` `Database Systems`

- Built transactions, relational constraints, automatic indexing, and query execution
- Developed separate AI skills for SQL drafting and result explanation
- Created a business analytics workspace with schema browsing, SQL execution, AI questions, and data exports

### Sportsbook Arbitrage Engine

A full-stack platform that ingests live sportsbook data and identifies profitable arbitrage opportunities.

**[Backend Repository](https://github.com/cspannuth/Arbitrage_Engine)** · **[Frontend Repository](https://github.com/cspannuth/Arbitrage_Frontend)**

`Python` `FastAPI` `PostgreSQL` `React` `REST APIs`

- Built a FastAPI backend to ingest and process live market data
- Designed REST APIs for exposing detected arbitrage opportunities
- Built a PostgreSQL-backed data layer and React interface for visualization
